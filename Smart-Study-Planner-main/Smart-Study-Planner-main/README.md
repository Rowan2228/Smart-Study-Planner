# 🤖 IntellectoNova – AI-Powered Smart Study Scheduler

IntellectoNova is an intelligent study planning application designed to help students organize their learning process efficiently. By combining a modern glassmorphic user interface with AI-powered recommendations, the platform creates personalized study schedules and provides actionable strategies to improve productivity and exam preparation.

## 📌 Overview

Managing multiple subjects, deadlines, and exam preparations can be challenging. IntellectoNova simplifies this process by allowing students to enter subject details such as exam dates, difficulty levels, topics, and importance. The application then generates a structured study schedule and enhances it with AI-generated recommendations to maximize learning efficiency.

The platform is built using HTML, CSS, and JavaScript, while OpenRouter-powered AI provides personalized study guidance and planning suggestions.

---

## ✨ Features

### 📚 Smart Study Planning
- Add and manage multiple subjects and topics.
- Set exam dates, difficulty levels, and priority rankings.
- Automatically organize subjects based on urgency and importance.

### 🧠 AI-Powered Recommendations
- Generates personalized study strategies.
- Suggests effective time allocation methods.
- Provides productivity and revision tips.
- Helps students improve focus and exam readiness.

### 💬 AI Study Assistant
- Interactive chatbot for study-related queries.
- Offers guidance, learning techniques, and motivational support.
- Powered by OpenRouter AI models.

### 🎨 Modern Glassmorphic Design
- Attractive glass-effect user interface.
- Soft gradient background for a clean and professional appearance.
- Responsive design compatible with desktops, tablets, and mobile devices.

### ⚡ Dynamic User Experience
- Real-time updates without page refresh.
- Instant schedule generation.
- Smooth and interactive user interface.

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Rowan2228/Smart-Study-Planner.git
cd Smart-Study-Planner
```

### 2️⃣ Configure API Key

Open the JavaScript file and replace the placeholder API key with your OpenRouter API key:

```javascript
const API_KEY = "YOUR_OPENROUTER_API_KEY";
```

### 3️⃣ Run the Project

Simply open the `index.html` file in your preferred web browser.

No additional installation or build tools are required.
